   - **Chế độ phóng to Lightbox toàn màn hình** (nhấp vào ảnh để xem kích thước gốc siêu nét, hỗ trợ phím mũi tên và phím `Esc`).

3. **Thông Tin Bản Mod Chi Tiết**:
   - Tên game, phiên bản (`v2.11`), nhà phát hành, dung lượng tải, hệ điều hành Android yêu cầu.
   - Huy hiệu bảo mật: **100% VirusTotal Clean**, Không cần Root (**No Root**).

   - Bảng thông số kỹ thuật và hướng dẫn cài đặt chi tiết cho game thủ (`.apk` và `.obb`).

4. **Hệ Thống Tải Về Trực Tiếp (Direct VIP Download)**:

5. **Bộ Lọc & Tìm Kiếm Thời Gian Thực**:

## 🚀 HƯỚNG DẪN ĐƯA TRANG WEB LÊN VERCEL

Trang web đã được cấu hình tối ưu sẵn file `vercel.json` để triển khai trong 30 giây mà không cần cấu hình phức tạp:

### Cách 1: Đưa lên Vercel qua GitHub (Khuyên dùng)
1. Đẩy thư mục mã nguồn này lên kho lưu trữ GitHub của bạn:
   ```bash
   git init
   git add .
   git commit -m "Kho mod game android sang trong"
   git branch -M main
   git remote add origin https://github.com/Tên_Tài_Khoản_Của_Bạn/Tên_Repo.git
   git push -u origin main
   ```
2. Truy cập [vercel.com](https://vercel.com) và đăng nhập bằng tài khoản GitHub.
3. Nhấp nút **"Add New..."** -> **"Project"**.
4. Chọn kho lưu trữ vừa tải lên và nhấn **"Deploy"**.
5. Vercel sẽ tự động phát hiện website tĩnh và cung cấp đường dẫn website trực tiếp (ví dụ: `https://ten-du-an.vercel.app`) hoàn toàn miễn phí, có sẵn SSL HTTPS bảo mật cao!

### Cách 2: Triển khai trực tiếp bằng Vercel CLI
Nếu bạn đã cài sẵn Node.js trên máy tính:
1. Mở cửa sổ dòng lệnh tại thư mục này và chạy:
   ```bash
   npx vercel
   ```
2. Trả lời các câu hỏi mặc định của Vercel (bấm `Enter` chấp nhận thiết lập mặc định).
3. Đợi khoảng 10 giây là trang web sẽ online trực tiếp trên internet!
